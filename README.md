# Internet Speed Tester

Простой скрипт на Python для замера скорости интернета.
Делает 10 последовательных запросов к указанному URL (например, к тяжёлой картинке),
замеряет время, объём скачанных данных и выводит среднюю скорость в **МБ/с**.

## Требования
- Python 3.7+
- pip

## Установка

```bash
git clone https://github.com/YOUR_USERNAME/internet-speed-tester.git
cd internet-speed-tester
pip install -r requirements.txt
